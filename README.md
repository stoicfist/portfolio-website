# Personal Portfolio Website

Welcome to my personal portfolio website.

This project showcases my work, technical skills, certifications, and personal projects. The website serves as a central place where I document my journey as a software developer and continuously improve both the content and the implementation.

## Tech Stack

- HTML5
- CSS3 (Grid Layout)
- Amazon S3 (Static Website Hosting)
- Amazon CloudFront (CDN)

## Features

- Responsive design
- Grid-based layout
- Fast global content delivery via CloudFront
- Lightweight static architecture
- Optimized for desktop and mobile devices

## Purpose

The goal of this project is to provide a clean, fast, and maintainable portfolio while demonstrating practical experience with frontend development and AWS cloud deployment.

The website is continuously updated as I complete new projects, competitions, and certifications.

## Note

The current project structure is still a work in progress and could be organized more cleanly. As the portfolio continues to grow, I plan to refactor the directory structure to improve maintainability and scalability.

For now, I'm prioritizing new features and content over restructuring the project.
