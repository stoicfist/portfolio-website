Energy Data Hackdays

Secure Power Quality Metering via SCION

Developed a Rust-based prototype for power quality monitoring, collecting real-time measurements from Janitza UMG 605-Pro via Modbus TCP and transmitting them through a simulated SCION network using PocketSCION. Contributed to anomaly detection and monitoring of electrical measurements.

Rust SCION Modbus TCP Raspberry Pi 5 Network Programming Anomaly Detection
